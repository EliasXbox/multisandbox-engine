# v1.3.0 — Survival Foundation Update

Minecraft Survival now plays inside the shared Mindustry world, with resource gathering, building recipes, inventory interactions and combat. The development build was tested by the creator for approximately one hour across **Serpulo and Erekir**; the English release and final Erekir recipes received separate automated validation.

## Highlights

- Serpulo and Erekir world reconstruction, with the core area playable before the rest of a large map finishes.
- Faster bounded map streaming, asynchronous saves, reconnect handling and cleanup between maps.
- All **245 survival-buildable structures** from Mindustry 160.4 represented and available through the MSE Workshop, with resource costs and native horizontal footprints.
- Core/building inventory withdrawal and deposit, plus supported item filters and links.
- Shared player/unit health, melee and bow combat, and Minecraft armor reduction.
- Directional stair conveyors and full-volume recovery of buildings, manufactured walls and **26 natural wall types**.
- English MSE menus, resource/building names, messages and installation/gameplay documentation. Older saved resource tags remain supported.
- **Erekir progression:** 4 beryllium → 4 oak planks; 4 graphite → 1 iron ingot. Available in the crafting grid and workshop. Graphite requires only a wooden pickaxe.

## Downloads and setup

Download the Minecraft JAR, Mindustry ZIP and Relay ZIP from this release and use them together. Follow the [installation tutorial](https://github.com/EliasXbox/multisandbox-engine/blob/v1.3.0/docs/installation.md) and [Survival guide](https://github.com/EliasXbox/multisandbox-engine/blob/v1.3.0/docs/survival-foundation.md).

Tested with Minecraft Java **1.20.1/Purpur**, Mindustry **160.4** and Node.js **24.19.0**. The Minecraft plugin needs Java **17 or newer**. The default bridges connect to a local Relay on port **8080**.

**Use a 100% empty, dedicated primary Purpur world.** Existing terrain conflicts with World Sync. Back up saves and plugin/Relay data, then stop both games and the Relay before upgrading. Keep only one active MSE plugin/mod version.

## Compatibility and validation

Campaign / story mode is **partially compatible** on Serpulo and Erekir. Mindustry retains objectives, research, waves and sector progression. Specialized controls such as logic editors and full factory/payload interfaces are not replicated in Minecraft.

Validation covers map transitions, million-cell bounded streaming, asynchronous persistence, resource identity, direction conversion, combat and duplicate-hit protection, real Mindustry unit armor/environment behavior, real building inventory/configuration calls, all 245 model materials/costs, wall recovery and both new Erekir recipes. Tests use isolated fixtures or in-memory worlds and do not access live saves.

MSE remains experimental. Transfer journals support normal retries; independent game saves are not one atomic transaction after an operating-system failure.
